01 / Conversational applications

TopAgent

A conversational interface for finding and comparing products, with saved items and account chat history.

JavaScript / Claude / Gemini / Express / Supabase

Source code ↗Open demo ↗

Public demo available

The problem

Product discovery involves more than a single search: people compare alternatives, refine requirements and return to earlier results. This project connects that conversation to a usable product interface.

How it works

The application combines a JavaScript frontend, an Express API and Supabase-backed account features. Model-assisted responses support the product conversation; retailer links provide a path to the product.

Question → Express API → model / product workflow → response → saved items & history

Engineering decisions

  1. Keep discovery separate from purchasing

    Retailer links are available. Automatic checkout and payments are not enabled.

  2. Make deployment behavior explicit

    Vercel routing and response headers were corrected, and repeatable checks were added to CI.

  3. Preserve a useful interface

    Search, comparisons, saved products and chat history are part of the application rather than a standalone model prompt.

What was checked

34 automated checks passed. A greeting request to the deployed API returned HTTP 200 with an appropriate Uzbek clarification response.

Verification recorded October 30, 2026. Automated checks and live service checks cover different things.

Current limits

The greeting check does not verify every retailer, product query, account flow or price-tracking task. Those flows need separate end-to-end checks before broader reliability claims.

Next step

Extend live checks to product search, comparison and account history, with explicit handling for unavailable external services.
