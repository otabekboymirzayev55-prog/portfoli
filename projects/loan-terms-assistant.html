03 / Retrieval & grounding

Loan Terms Assistant

A document question-answering application with page references, topic restrictions and a separate grounding check.

Python / Gradio / Qdrant / RAG

Source code ↗

Gemini document Q&A verified locally · no public demo

The problem

Loan terms require precise answers tied to the actual document. A plausible answer about a fee is unhelpful if that fee does not appear in the supplied terms.

How it works

PDF text is split into overlapping, page-labelled chunks and embedded through Gemini. Qdrant retrieves relevant clauses. A topic gate, answer generation step and grounding check sit behind the Gradio chat interface.

Question → topic gate → retrieval → cited draft → grounding check → answer / refusal

Engineering decisions

  1. Do not invent missing terms

    The answer prompt uses retrieved context only, asks for page references and returns an explicit absence response when terms are not stated.

  2. Keep indexing out of the chat path

    Document ingestion is an explicit preparation step. A chat request does not silently rebuild or replace an index.

  3. Preserve data during provider changes

    Gemini uses a new collection. Embeddings finish before collection creation, preventing provider errors from leaving an empty new index. Local storage can be selected without removing cloud settings.

What was checked

10 automated checks passed. A permitted local PDF produced 60 indexed chunks. In a browser test, the assistant described repayment terms with references to pages 2, 3 and 5. It reported missing penalty information and refused an unrelated poetry request.

Verification recorded October 30, 2026. Automated checks and live service checks cover different things.

Current limits

Grounding checks reduce unsupported responses but do not guarantee correctness. The current verified application runs locally. A cloud Qdrant connection was unavailable, so local storage was selected; there is no public demo.

Next step

Add a labelled evaluation set for answerability, citation accuracy and refusal behavior before making broader quality claims.
