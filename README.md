# Otabek Boymirzayev — AI/ML Engineer

A buildless, reading-focused portfolio with four project studies, two implementation notes and a searchable directory of all ten public repositories. Education information is intentionally omitted.

## Structure
- `index.html`: introduction, selected projects, technical notes, repository directory and direct contact links.
- `projects/`: four project studies with architecture, decisions, verification and limits.
- `notes/`: original implementation notes based on documented project checks.
- `projects.json`: repository catalogue; its entries are also rendered into static HTML, so the content works without JavaScript.
- `script.js`: progressive-enhancement project filtering only.
- `styles.css`: responsive layout, local system fonts; no runtime CSS framework or external font dependency.

## Preview
Run `python -m http.server 8080` in the repository root. GitHub Pages serves the same static files without a build step.
